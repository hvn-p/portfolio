# Maquette v2 : vitrine de projets façon agence

Brouillon en HTML et CSS statiques pour caler le style avec Pierre avant Next.js. Pages : accueil, page Work, une page par projet (Fruggr, CarbonScore, Abacus, Estuaire, baudrier, orchestrator), À propos. Mode visiteur : Persuade.

- Visiteur : un employeur qui recrute un développeur, souvent arrivé depuis une candidature, qui veut voir ce que Pierre a réellement construit (décision du 2026-10-20, qui remplace le client freelance).
- Action : ouvrir un projet, puis contacter Pierre.
- Ce que le visiteur retient en dix secondes : full stack, programmation avec l'IA, développement de systèmes d'IA.
- Preuves : les projets, par ce que Pierre y a construit, et en images quand il y en a (captures d'estuaire.fr, d'Abacus sur données fictives, visuels publiés par Fruggr).
- Engagements : thème sombre et sobre ; format agence au niveau de hello-superchouette.com, sobha-privy-collection.com, gilhuybrecht.com ; pas de citation de sources ; accessible.
- Refusé : la palette colorée de la v1, le CV interactif comme forme principale.

Décisions ouvertes : le canal de contact.

## Direction contract

THESIS: The agency showcase played straight, at the craft level of Pierre's three references: the work leads in large imagery, and a project without imagery leads by what was built; type is big and quiet, chrome is minimal. Refuses the interactive CV and any decorative color.

OWN-WORLD: Tinted near-black ground #0D0D0E with a raised surface #161618, warm off-white ink #EDEBE6, two quieter inks for secondary text, hairline rules at low opacity. No accent color: color comes only from the projects' own imagery. One grotesque family, Schibsted Grotesk, ranked by size and weight; no monospace.

STORY: The visitor sees a one-line thesis, then three projects as full-screen pinned scenes (Fruggr, CarbonScore, Abacus: professional work first), then a link to the Work page, where all six sit in a grid of framed pictures, a sentence standing in for the picture a project lacks; opens one, reads what was built and with what, and reaches contact from any page.

FIRST VIEWPORT: Monogram left and the nav right in a thin top bar; a two-line display statement; the availability, the local time and a short supporting line beside it; the name across the full width; a foot line with the scroll cue. The hero fills the first screen, and the first project scene starts right below it.

FORM: The category standard (canon), chosen by Pierre over the rolled direction; seed key c59e0eb7.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
